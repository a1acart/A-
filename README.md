# Forma

Original responsive one-page audio product concept. Semantic HTML, CSS, JavaScript, and custom SVG artwork. No runtime dependencies or external assets.

## Preview

From this directory run `npm run dev`, then open port 3000 in your development environment's preview. Python 3 is required for the server.

## Build and deploy

Run `npm run build` with Node.js 18+. Deploy the generated `dist/` directory to any static host. For Git-connected hosting, set the build command to `npm run build` and the output directory to `dist`. No environment variables or backend are needed. Use `npm run preview` to serve the production build on port 3000.

Navigation scrolls to sections. The call to action opens a product-details dialog with Escape and focus-return support. Animations respect reduced-motion preferences. Forma One is fictional and is not available for sale.
